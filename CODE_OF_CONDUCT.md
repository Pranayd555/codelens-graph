# Code of Conduct

We want CodeLens Graph to be a welcoming project for everyone, whatever their background or experience.

## Expected behaviour

- Be respectful and assume good intent; disagree about ideas, not people.
- Give and accept constructive feedback gracefully.
- Help newcomers — everyone started somewhere.

## Unacceptable behaviour

- Harassment, insults, or discriminatory language or imagery.
- Personal or political attacks, trolling, or deliberately derailing discussions.
- Publishing someone's private information without permission.
- Any other conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may edit or remove comments, commits, code and issues that break this code, and may temporarily or permanently ban contributors who do so. Report problems privately to the maintainer ([@Pranayd555](https://github.com/Pranayd555)); reports are kept confidential.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
